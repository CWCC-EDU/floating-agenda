# 浮屿 · 桌面透明日历

浮屿是一款 Windows 桌面日历小程序。它像壁纸一样**贴在桌面上**，看日历、记待办都在桌面完成；其他窗口打开时会自然地盖在它上面，不挡你工作。

**特点**

- 完整月历：从周一开始的 6 行月历，显示农历、节日、周数，今天是哪一个一目了然
- 任务写在日期格里：长文字自动换行，不会截断；自动编号 1. 2. 3.
- 完成打删除线：完成的条目保留文字、划上横线，不是打对钩
- 未完成自动顺延：最近 N 天没做完的任务自动挪到最新一天，N 可以在设置里改
- 重复任务：设了"每天 / 每周"等重复的任务，会提前把后续日程排好，不用等今天完成
- 输入即自动保存：敲下的内容自动写入本地，不需要再点保存按钮
- 不打扰：平时安静地贴在桌面底层；启动后直接显示，不在任务栏占位置

## 下载与安装

1. 打开本仓库的 **Releases** 页面，下载最新的 `Floating-Agenda-*.exe`
2. 双击运行即可，**无需安装**，删掉文件就等于卸载
3. 如果 Windows 弹出蓝色提示"已保护你的电脑"，点 **更多信息 → 仍要运行**

第一次打开后，日历就会出现在桌面上。它不会出现在屏幕下方的任务栏里，而是住在右下角的托盘（点任务栏的 `^` 小箭头能看到它的图标）。

## 基本操作

| 想做什么 | 怎么做 |
| --- | --- |
| 显示 / 隐藏日历 | 点托盘里的浮屿图标，或按 `Ctrl + Shift + Space` |
| 添加任务 | **双击日历上的日期格**，输入内容即自动保存 |
| 新建任务 | 托盘菜单"新建日程"，或按 `Ctrl + N` |
| 完成任务 | 双击那条任务，点编辑器里的完成 |
| 恢复未完成 | 双击已完成的任务，再点一次完成按钮 |
| 设置重复 | 双击任务，点编辑器里的"重复"，选每天 / 每周等；改回"不重复"会删除该系列所有日期的日程 |
| 改颜色 | 双击任务，点编辑器工具栏的圆点 |
| 换月份 | 托盘菜单"上一月 / 下一月 / 回到今天" |
| 移动桌面便签 | 打开便签后，按住便签顶部标题栏拖动；位置会自动记住 |

## 移动和调整大小

日历平时是**固定**的，不会误碰。

1. 点日历右上角的菜单，勾选 **调整位置和大小**
2. 按住日历主体拖动位置；拖四周的边或右下角小三角调整大小
3. 调好后**再点一次右上角菜单，取消勾选**，位置就锁定了

## 托盘菜单能做什么

右键托盘里的浮屿图标（或左键直接显示 / 隐藏）：

- 显示 / 隐藏日历、新建日程
- 上一月 / 下一月 / 回到今天
- 显示日程：只看全部、待办或已完成
- 自动编号、显示周数、显示农历与节日、未完成任务自动顺延 —— 随手开关
- 跟随 Windows 启动 —— 开机自动出现
- **背景、透明度与更多设置…** —— 所有详细设置都在这里
- 退出浮屿

## 设置里有什么

托盘菜单 → 背景、透明度与更多设置…：

- **外观**：背景颜色（或透明）、不透明度 0–100%、日历格间距、今天边框的颜色
- **布局**：浮动月份 / 完整月份 / 固定单行 / 浮动单行四种形态，最大行数、列数
- **文字**：字体、字号、颜色自适应，条目多时自动缩小，超出上限变成格内滚动
- **任务**：顺延天数、完成后自动排到末尾、项目符号样式
- **其他**：便签、提示音、节气与宜忌、快捷键、开机启动、检查更新

### 显示桌面和桌面图标

按 `Win+D` 显示桌面时，日历仍停在桌面。在「设置 → 高级 → 桌面图标层级」可以选择日历在图标上方或下方，默认在图标上方。选择下方时，日历会给重叠的图标和名称留出空位。普通应用窗口优先显示，两种设置下都能盖住日历。若桌面图标突然全部点不动，可以右键托盘图标，选择「修复桌面图标点击」。

### 顺延和便签

在「设置 → 日历」打开「未完成任务自动顺延」后，可以分别开启「顺延任务高亮」和「在原日期保留顺延分身」。两项默认关闭，高亮默认红色，可自行换色。原日期的「顺延」标记可点击，直接打开当前任务。

在日历右上角菜单或「设置 → 便签」点「新建便签」，每次打开一张独立窗口，重叠时便签显示在日历上方。关闭窗口会保留内容，可从「管理便签」重新打开。销毁会删除该便签，管理页还可以一次销毁已关闭的空白便签。 在便签内容区右键可以插入可点击的勾选框。选中文字后，在便签底栏更换字体颜色或切换删除线，格式会随便签保存。

## 本机数据与坚果云同步

本机数据保存在 `%APPDATA%\floating-agenda\floating-agenda.json`。

需要多设备同步时，在「设置 → 同步」填入坚果云邮箱和[第三方应用密码](https://help.jianguoyun.com/?p=2064)。账号和应用密码通过 Windows 系统加密保存。连接后，日程、便签和设置仍保存在本机，也会通过 HTTPS 同步为坚果云中的 `floating-agenda/floating-agenda.json`。两边分别修改时由你决定保留哪份，覆盖前会在本机 `sync-backups` 保存备份。

## 常见问题

**双击没反应 / 找不到窗口？**
它可能正藏在托盘里。点任务栏右下角的 `^`，点浮屿图标，或按 `Ctrl + Shift + Space`。

**Windows 提示"已保护你的电脑"？**
因为应用没有花钱购买代码签名。点 **更多信息 → 仍要运行** 即可。介意的话也可以按下面的开发者方式自己打包。

**卸载？**
从托盘菜单选"退出浮屿"，然后删除下载的 exe 文件。想连数据一起清掉，再删除 `%APPDATA%\floating-agenda` 文件夹。

## 开发者构建（外行可跳过）

需要 [Node.js](https://nodejs.org/) 环境：

```bash
npm install        # 安装依赖
npm run dev        # 本地开发运行
npm run dist       # 打包为便携版 exe（输出在 release/ 目录）
```

技术栈：Electron + React + TypeScript + Vite，主进程代码在 `electron/`，界面代码在 `src/`。
